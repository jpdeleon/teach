## About

These materials cover a range of topics in physics, astronomy, data analysis, and statistics. Each course is structured as a Jupyter Book chapter with references, code examples, and interactive notebooks.

## Getting Started

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Build the book:

```bash
jupyter-book build .
```

View the book locally:

```bash
jupyter-book serve .
```
